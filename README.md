# Mock Exam Timetable 📅

A simple, interactive exam timetable I made because staring at a list of exam dates is depressing.

Built for my January 2027 IGCSE mock exams, but feel free to modify it for your own schedule.

## Features

- 📅 Interactive calendar with exam dates and times
- ✅ Mark exams as completed
- 💾 Automatically saves progress locally
- 🟢 Highlights exam-free days
- 🔍 Filter by week
- 📱 Mobile-friendly layout
- 🌐 Works offline — no server required

## Getting Started

1. Download or clone this repository.
2. Open `mock_exams_2027.html` in your browser.
3. That's literally it.

No dependencies, installations, or accounts required.

## Tech Stack

Just HTML, CSS, and JavaScript. Nothing fancy.

## Customisation

Edit the exam data in the HTML file to replace my exams with yours.

## Why Does This Exist?

I had mock exams coming up and wanted a nicer way to see how cooked I was.

That's about it.
